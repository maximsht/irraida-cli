# IRRaida CLI

Инструмент для работы с фондом. Одна папка — один проект: ваша компания или группа
компаний. В этой папке вы либо **подаёте заявку на инвестиции**, либо **сдаёте
отчётность мониторинга** по портфельной компании.

Работает на вашем компьютере: документы читаются локально, в фонд уходит только то, что
вы явно подтвердили к отправке.

Здесь публикуются готовые сборки. Исходный код закрыт.

## Установка

Скопируйте текст ниже целиком и отдайте своему ИИ-агенту — Claude Code, Codex, Cursor
или любому другому, у которого есть доступ к терминалу.

---

**Установи мне IRRaida CLI и разверни рабочую папку проекта.**

1. Определи мою операционную систему и установи CLI.

   macOS и Linux:

   ```sh
   curl --proto '=https' --tlsv1.2 -LsSf https://github.com/maximsht/irraida-cli/releases/latest/download/irraida-cli-installer.sh | sh
   ```

   Windows (PowerShell):

   ```powershell
   powershell -ExecutionPolicy Bypass -c "irm https://github.com/maximsht/irraida-cli/releases/latest/download/irraida-cli-installer.ps1 | iex"
   ```

2. Проверь установку: `irraida version`. Если команда не найдена — открой новый
   терминал: установщик прописал путь, но текущая сессия его ещё не видит.

3. Спроси меня, что мы делаем — подаём заявку или сдаём отчётность мониторинга, — и
   разверни папку проекта:

   ```sh
   irraida init ./моя-компания --mode application   # или --mode monitoring
   ```

   Без `--mode` команда откажет: режим определяет, с каким контуром фонда работает
   папка, и выбирать его за меня нельзя.

4. Покажи мне ссылку, которую напечатает `init`. Я схожу по ней, заберу ключ и вернусь.

5. Скажи мне выполнить `irraida auth login` и вставить ключ. **Ключ ввожу я, не ты** —
   он не должен попасть ни в файлы, ни в историю команд, ни в твой контекст.

6. Прочитай `CLAUDE.md` или `AGENTS.md` в созданной папке: там описана раскладка папок
   и порядок работы именно для выбранного режима. Они разные.

7. Зарегистрируй MCP-сервер `irraida` в конфиге своего хоста — готовый сниппет даёт
   `irraida init --print-mcp-snippet`. Если ты Claude Code, файл `.mcp.json` уже создан
   в папке, делать ничего не нужно.

8. **Перезапустись в этой же папке.** Конфиг MCP читается один раз при старте: без
   перезапуска новые инструменты не появятся.

## Что появится в папке

Раскладка зависит от режима.

**Заявка на инвестиции:**

```text
моя-компания/
  sources/    документы, которые вы предоставили
  work/       черновики агента
  package/    собранный пакет — то, что уйдёт в фонд
```

**Отчётность мониторинга** — периоды не затирают друг друга, прошлые остаются:

```text
моя-компания/
  reports/
    01.07.2026/
      materials/   материалы периода, которые кладёте вы
      work/        черновики агента
      report/      то, что уйдёт в фонд за этот период
    01.10.2026/
      ...
```

В обоих случаях исходящая папка отделена от черновиков намеренно: вы подтверждаете
отправку и должны видеть ровно то, что уходит.

## Что делает установщик

Кладёт один исполняемый файл `irraida` в `~/.cargo/bin` и записывает receipt установки,
по которому работает обновление.

Чтобы команда `irraida` находилась в новых терминалах, установщик дописывает одну
строку в файлы настроек вашей оболочки — `.profile`, `.bashrc`, `.zshrc` и аналогичные:

```sh
. "$HOME/.cargo/env"
```

Больше ничего в систему не добавляется. Если будете удалять CLI, уберите и эту строку —
иначе оболочка будет ругаться на отсутствующий файл при каждом запуске.

## Обновление

```sh
irraida update check    # посмотреть, есть ли новая версия
irraida update apply    # установить
```

CLI сам проверяет обновления не чаще раза в сутки и сообщает о новой версии. Проверка не
блокирует работу и не отправляет ничего, кроме запроса файла версий: ни ключей, ни путей,
ни ваших данных.

Обновление ставится только после вашего подтверждения. Перед заменой сохраняется
предыдущая версия — если новая не запустится, откат произойдёт автоматически.

| Система | Архитектура |

| macOS | Apple Silicon и Intel |

Установка на всех трёх проверяется автоматически после каждого выпуска.

## Если скачивали архив вручную

Команда установки выше работает без предупреждений операционной системы. Но если вы
скачали `.tar.gz` или `.zip` со страницы релизов **браузером**, macOS пометит файл как
загруженный из интернета, и Gatekeeper откажется запускать программу.

Это лечится одним из двух способов:

- в Finder щёлкнуть по файлу правой кнопкой и выбрать «Открыть»;
- либо снять пометку: `xattr -d com.apple.quarantine irraida`.

Проще воспользоваться командой установки — она этой проблемы не создаёт.

## Безопасность

Ключ доступа хранится в системном хранилище секретов вашей ОС — Keychain на macOS,
Credential Manager на Windows, Secret Service на Linux. Он не пишется в файлы проекта и
не передаётся ИИ-агенту.

У заявки и у мониторинга разные контуры и разные ключи. Они хранятся раздельно и не
заменяют друг друга.

Файл версий подписан криптографически, и CLI проверяет подпись перед установкой
обновления. Ваши документы остаются на компьютере: в фонд уходит только собранный
результат и только после вашего подтверждения.
